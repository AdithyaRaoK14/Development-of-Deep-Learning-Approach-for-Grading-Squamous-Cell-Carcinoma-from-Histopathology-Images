# Deep Learning–Based Grading of Squamous Cell Carcinoma

## 📌 Overview
This project focuses on automated grading of **Oral Squamous Cell Carcinoma (OSCC)** from histopathology images using deep learning and explainable AI.

## 🎯 Objectives
- Binary classification: SCC vs Adenocarcinoma
- Multi-class grading: Well, Moderate, Poor differentiation
- Model explainability for medical trust

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- CNN Architectures: InceptionV3, DenseNet121, MobileNetV2, ConvNeXt-Tiny, EfficientNetB0
- Grad-CAM
- Gradio
- Ollama (Phi-3 Mini)

## 📊 Methodology
- Trained and evaluated multiple CNN architectures on **LC25000 dataset**
- Implemented **class-balanced training and data augmentation**
- Generated visual explanations using **Grad-CAM**
- Deployed a Gradio interface integrated with an LLM for interpretation summaries
